# DevAgency - Landing Page Profesional

Landing page premium con estética "Dark Developer" para agencias de desarrollo.

## 🚀 Características
- **Diseño Moderno**: Dark mode premium optimizado para conversión.
- **Multipage**: 4 páginas de servicios detallados con sistema de pestañas.
- **Responsive**: 100% adaptable a móviles y tablets.
- **WhatsApp Directo**: Enlaces con mensajes predeterminados por servicio.

## 📁 Estructura
- `index.html`: Página principal.
- `rifas.html`: Sistemas de Rifas.
- `landings.html`: Landing Pages.
- `invitaciones.html`: Invitaciones Digitales.
- `catalogos.html`: Catálogos Virtuales.
- `style.css` / `script.js`: Estilos y lógica.

## ⚙️ Personalización
Variables principales en `style.css`:
```css
:root {
    --accent-primary: #007acc;
    --accent-secondary: #4fc3f7;
}
```
